
**##1 What does your dataset explore?**

This dataset explores cats listed for adoption from the RescueGroups Public API, and how long they took to be adopted from the time they became available for adoption. The data will help find correlations between cat charateristics and the amount of days a cat may spend in adoption care.

**##2 What is your dependent variable in the data you are pulling from?**

The dependent variable -'Length of Stay', was created by finding the number of days between the availableDate and adoptionDate.

**##3 Is this variable categorical or quantitative?** 

Quantitative - number of days.
